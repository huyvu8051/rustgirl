RustGirl is a Postman-style API client built entirely in Rust with egui/eframe. One small binary — no Electron, no webview, no background updater. Just requests, collections, and a response viewer that keeps up with you.

What it does

Everything a Postman tab does, none of the weight it carries.

Every screen below is a real screenshot from RustGirl's own headless test suite — this is exactly what you get, not a mockup.

Every request is already a curl command

Switch to the Code tab and RustGirl writes the equivalent curl for you — headers, auth, and body included. Copy it straight into a script, a bug report, or a teammate's DM.

Jump to any request without touching the mouse

Option/Alt+Space opens a fuzzy search across every collection you have. Type a few letters of a request name, an endpoint, or a theme setting — it's all in the same palette.

Nest folders as deep as your API actually is

Drag to reorder, right-click to rename or duplicate, and organize collections the way your API is actually shaped — not the way a flat list forces you to.

Script requests with Lua, not a walled-off DSL

Pre-request and post-response scripting through a pm.* API modeled on Postman's — set variables, run assertions, or fire a follow-up request from inside a real, sandboxed Lua interpreter.

Light, dark, or whatever your OS is already doing

One setting, applied everywhere immediately — no restart, no flash of the wrong theme.

Under the hood

No runtime to ship, no VM to boot.

The Lua interpreter is vendored and built from source by mlua — there's no system Lua to install, and nothing besides a C compiler on Linux.

Rust 1.85+, edition 2024 egui / eframe — native UI, no webview reqwest + tokio — async HTTP mlua — vendored Lua 5.4 rfd — native file dialogs AccessKit — screen-reader labels
Get started

Clone it, run it, keep it.

Requires Rust 1.85+. No account, no telemetry, no installer to trust.

terminal 
$ git clone https://github.com/huyvu8051/rustgirl.git
$ cd rustgirl
$ cargo run --release
   Finished release profile — RustGirl opens as a native window
